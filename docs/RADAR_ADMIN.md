# Radar Admin

The Django Admin contains Radar Sources, Scrape Runs, Scraped Event Observations, Duplicate Candidates, and County Coverage.

- Review source compliance before enabling it.
- Inspect validation issues and provenance on each observation.
- Approve observations scoring at least 60.
- Use **Publish selected observations** to create canonical events.
- Never treat a county with zero known events as proof that no events exist there.
