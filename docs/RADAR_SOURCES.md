# Radar sources

## New source workflow

1. Add Source Candidate.
2. Review the source and its rights/terms.
3. Determine the acquisition method.
4. Prefer API, feed, or JSON-LD.
5. Configure crawl policy and honest rate limits.
6. Configure or build the adapter.
7. Create fixtures.
8. Write tests.
9. Run a test crawl.
10. Inspect staged observations.
11. Verify duplicate behaviour.
12. Approve the source.
13. Enable scheduling.
14. Monitor health.

Unknown sources remain disabled. Candidate records do not constitute permission to crawl or republish.
